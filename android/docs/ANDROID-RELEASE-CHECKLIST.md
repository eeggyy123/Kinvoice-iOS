## 4. 数据安全表建议口径（以最终版本复核）

当前本地模式不从设备向开发者收集数据。用户主动使用 AI 时，应用会传输“用户内容”（问题、口述文字、候选家庭记忆），用途为提供应用功能；传输过程加密；后端设计为不保留正文；不与广告商共享。麦克风音频本身不上传，系统语音识别是否由设备厂商在线处理取决于用户设备，需在真机和市场问卷中如实披露。

## 5. 阻断发布的事项

以下任一项未完成时不得宣称“已可直接上架”：

1. CI/本机 release 构建或 Lint 未通过；
2. 没有正式签名密钥及备份；
3. 隐私政策没有公网 URL或运营主体信息；
4. AI 后端仍是 HTTP、暴露模型密钥或记录家庭正文；
5. 市场数据安全声明与实际 SDK/网络流量不一致；
6. 没有在目标 ROM/Android 版本验证录音与删除。
